Privacy policy

Last updated 20 November 2026. Applies to the Mergeline extension and to this website.

Short version: Mergeline collects nothing and makes no network requests of its own. It runs git on your computer. Fetch and push reach your own remotes, and only when you ask for them.

The extension

  • No telemetry or analytics. Mergeline does not record or report which commands you use, how often you open the graph, errors, repository names, or anything about your machine.
  • No account. There is no sign-in, licence key or registration, so there is no personal data about you to hold.
  • No network requests of its own. Mergeline has no server. It does not check for updates, ping anything, or download avatars or other images. The graph view loads no remote scripts, fonts or styles.
  • Git runs locally. To draw the graph, Mergeline runs git commands such as git log, git for-each-ref, git status and git show in your workspace. Their output is shown in the editor and is not sent anywhere.
  • Remotes only when you ask. A few actions talk to a remote because that is their whole purpose: Fetch, pushing a branch or tag, and deleting a branch or tag on the remote. They go to the remotes configured in your repository (for example origin), and they run only when you choose them. When VS Code’s built-in git extension is available, push and fetch go through it, so authentication uses your existing credential helper or the editor’s sign-in prompt. Mergeline never sees or stores your credentials.
  • Your git configuration still applies. Because Mergeline runs real git, anything you have set up in git runs too: hooks such as pre-push, credential helpers, and so on. Those are yours, not Mergeline’s.
  • Local state. Settings live in your editor’s settings like any other extension’s. Anything Mergeline remembers between sessions stays in the editor’s local storage on your computer.

Your editor and the extension registry

VS Code, VSCodium, Cursor and Windsurf have their own telemetry settings, and VS Code’s git extension can fetch on its own if its git.autofetch setting is on. Extension registries count downloads. Those belong to the editor or the registry, not to Mergeline, and their own privacy policies cover them.

This website

This site is static HTML hosted on GitHub Pages. It sets no cookies, has no analytics or forms, and loads no third-party scripts, fonts or trackers. As the host, GitHub may process technical data such as IP addresses in its server logs; see the GitHub General Privacy Statement.

Check it yourself

Mergeline is open source under the MIT licence. The full source is on GitHub, so you can confirm everything above by reading the code or by watching the extension’s network traffic.

Changes

If this policy changes, the new version will be published on this page with a new date, and the change will be visible in the repository history.

Contact

For privacy questions, open an issue at github.com/janwan2003/vscode-commit-graph/issues. Issues are public, so leave out repository contents, remote URLs and tokens you would not want published.
